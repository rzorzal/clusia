PR Reviews for Humans

A macOS app for reviewing pull requests carefully, with your own AI tools at your side. Free and open source.

Install it with one line in Terminal:

curl -fsSL https://raw.githubusercontent.com/rzorzal/clusia/main/install.sh | bash

Install guide → Quick start →

Review

A review you control

Open a pull request in a local worktree. Write comments on the diff and keep them as a draft that follows the code when the author pushes again. Publish everything as one GitHub review when you are ready.

Agent

Your harness, your models

Claude Code, Codex or a command of your own reads the pull request with you and helps with diagrams, security notes and audits. It reads, you decide: anything more it wants to do waits for your answer. Nothing is sent anywhere you did not choose.

Menu bar

Always at hand

A menu bar popover shows what is waiting for you, which saved reviews went stale and how your review activity looks over the last weeks.
