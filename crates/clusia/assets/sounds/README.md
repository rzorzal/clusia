# Notification sounds

`leaf.aiff`, `drop.aiff`, `chime.aiff` and `tick.aiff` are generated by `scripts/gen-sounds.py`
from sine partials and an exponential decay. They contain no recorded or third-party audio.
The script and its output are dedicated to the public domain (CC0 1.0). Regenerate with `python3 scripts/gen-sounds.py`;
the output is byte-for-byte reproducible.
